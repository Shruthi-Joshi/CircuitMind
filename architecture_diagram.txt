---

**Key Technical Flow**

1. **Upload & Queue:** The user uploads a BOM via Next.js. FastAPI pushes the job to BullMQ/Redis and immediately returns a `job_id`.
2. **Async Agent Stream:** BullMQ triggers the LangGraph Multi-Agent Engine. Real-time execution logs stream back to the UI via Server-Sent Events (SSE).
3. **Data Extraction & Vector RAG:** Document AI parses component line items, while `pgvector` in PostgreSQL executes semantic similarity searches for drop-in component substitutes.
4. **Human Interception:** If a stockout is detected, LangGraph triggers an interrupt, displaying a side-by-side spec comparison card in the UI.
5. **Approval & PO Finalization:** Clicking **Approve** resumes the graph, running the PO Generator Agent to save multi-vendor split orders directly to the database.
